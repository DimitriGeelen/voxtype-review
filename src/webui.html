Actions

Each action is a command. The transcript goes in on stdin, whatever the command prints comes back out. Press 1–9 in the popup to run one. It does not have to involve a model — sed, a script, a translation CLI all work.

Restore shipped actions loads the current built-in set into this editor without saving — useful if your file predates a fix to them. Nothing changes on disk until you press Save.

Save rewrites the file from this list, so hand-written comments in it are not preserved. Opening this page only reads. The previous version is always kept as config.toml.bak.

Dictation settings

These live in voxtype's own config, not ours — they decide what the popup is handed in the first place. Only the ones this workflow depends on are here; the rest stay on voxtype's own dashboard, linked below.

A change here needs the voxtype daemon restarted before it takes effect. Restart it the same way you normally start it. Under systemd that is systemctl --user restart voxtype.
If the push-to-talk key stops responding afterwards, the daemon came up without access to the keyboard — check with journalctl --user -u voxtype | grep -i hotkey, and start it instead from a terminal whose session has the input group.

Each save edits only that one line and keeps a timestamped backup, so the comments in that file survive. For everything else — audio devices, VAD, feedback sounds, the other ~30 settings — use voxtype's dashboard.

Try one

Run an action against text you type here, without dictating anything. Uses the action as currently shown above — save first if you want the popup to agree.

The popup's keys

Enter accept  ·  1–9 run an action  ·  Up/Down select, Space run  ·  e edit by hand  ·  Ctrl+Enter accept from anywhere  ·  Esc cancel

Esc does not lose your words. Cancelling emits the original transcript — exactly what you would have got without this installed. No key in the popup throws a dictation away.
